# Справочник Linux-команд для системного администратора

Интерактивный справочник: **269 команд и конструкций**, **242 готовые связки** с понятным описанием на русском, 31 раздел в пяти этапах.

**Открыть:** https://dmitry-morozov-dev.github.io/linux-sysadmin-cheatsheet/

## Что внутри

1. **Основы** — навигация и файлы, просмотр, поиск, обработка текста (grep, sed, awk), перенаправления, права и атрибуты, пользователи и sudo.
2. **Процессы и система** — кто сколько потребляет, поиск PID, дерево процессов, порты и файлы, сигналы и kill, зомби, D-state, OOM, приоритеты и лимиты; systemd, журналы, cron/at/таймеры, пакеты apt/dpkg и dnf/rpm.
3. **Диски** — разделы, файловые системы и fstab, LVM, RAID (mdadm), swap, поиск занятого места, архивы, rsync, dd, контрольные суммы.
4. **Сеть** — ip, nmcli, ss, ping, mtr, tcpdump, dig, curl, SSH (ключи, туннели, укрепление sshd), nftables/iptables/ufw/firewalld.
5. **Мониторинг, безопасность, контейнеры** — vmstat, iostat, sar, perf, fail2ban, SELinux, AppArmor, auditd, openssl, docker/podman и сборник связок для типовых задач.

На странице есть поиск по командам, флагам и примерам, фильтр по разделам, переключатель «Только опасные», раскрывающиеся карточки, содержание, светлая и тёмная тема.

Команды, отмеченные «Опасно», запускайте осознанно. Источники (man7.org, GNU, Arch Wiki, документация Red Hat, Debian и др.) перечислены внизу страницы.

## Устройство

Статический сайт без сборки: `index.html`, `style.css`, `app.js` (чистый JavaScript) и `data.js` (все данные справочника). Локально: `python3 -m http.server` в папке репозитория.
